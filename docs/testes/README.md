# Resultados dos testes

Cada integrante registra aqui os testes que executou no aplicativo, seguindo o roteiro `TESTE-COMPLETO.md` na raiz do projeto.

## Como registrar

1. Copie o arquivo `MODELO.md` desta pasta e renomeie com o seu nome, por exemplo `resultado-miguel.md`.
2. Execute os blocos do roteiro que ficaram com você.
3. Preencha a tabela: OK ou FALHOU, o que aconteceu e o celular usado.
4. Faça o commit:

```bash
git add docs/testes/resultado-seunome.md
git commit -m "test: resultados do bloco X no Android"
git push
```

Falhas encontradas viram tarefas de correção antes da apresentação.
